SearXNG Docker

Production-ready Docker Compose setup for a private, developer-focused SearXNG instance.

This is documentation only. The search instance is self-hosted and private — it does not run on this page.

Source on GitHub API reference Upstream SearXNG

What it is

SearXNG is a privacy-respecting metasearch engine. This repository packages a clean local or team deployment: SearXNG plus a Valkey cache, health checks on both services, multi-arch image publishing, and search shortcuts tuned for daily engineering work.

  • Docker Compose v2 stack: SearXNG + Valkey, both health-checked.
  • Two-command bring-up via make setup && make up.
  • CI: Compose validation, Hadolint, image build, real integration smoke test, Trivy SARIF.
  • Release workflow publishes multi-arch linux/amd64 and linux/arm64 images to GHCR with provenance and SBOM attestations.
  • Valkey is never exposed to the host; config is mounted read-only.

Quick start

git clone https://github.com/e-gleba/searxng-docker.git
cd searxng-docker
make setup
make up
make test

Then open http://localhost:8080.

Configuration

VariableDefaultDescription
SEARXNG_PORT8080Host port for SearXNG.
SEARXNG_BASE_URLhttp://localhost:8080/Public URL, especially behind a reverse proxy.
SEARXNG_SECRETrequiredSession secret. Generate a unique value; never commit it.
SEARXNG_IMAGEsearxng/searxng:latestSearXNG image to run.
VALKEY_VERSION8-alpineValkey image tag.
VALKEY_MAX_MEMORY256mbCache memory limit.

Main SearXNG settings live in core-config/settings.yml.

If you expose it

  • Put the service behind a TLS reverse proxy.
  • Set SEARXNG_BASE_URL to the external URL.
  • Keep SEARXNG_SECRET unique and private; .env stays out of Git.
  • Enable the SearXNG limiter — there is no authentication by design.
