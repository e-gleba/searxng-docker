# Code of Conduct

## Our pledge

We pledge to make participation in this project respectful, focused, and harassment-free.

## Expected behavior

- Be respectful and constructive.
- Keep discussions technical and actionable.
- Assume good intent, but accept correction quickly.
- Respect maintainers' time and project scope.

## Unacceptable behavior

- Harassment, insults, threats, or discriminatory language.
- Publishing private information without permission.
- Spam, trolling, or repeated off-topic comments.
- Abuse of issues, pull requests, or security channels.

## Enforcement

Maintainers may remove comments, close issues, block users, or report abuse to GitHub when needed.

## Scope

This code of conduct applies to project spaces, including issues, pull requests, discussions, and related community channels.
